Política de Privacidad de Distribuidora Alberdi

Última actualización: 26 de agosto de 2026

Distribuidora Alberdi respeta la privacidad de las personas usuarias de su aplicación. Esta Política de Privacidad explica qué información se procesa, para qué se utiliza y cómo puede contactarse con nosotros por consultas relacionadas con privacidad.

1. Responsable y contacto

La aplicación es administrada por Distribuidora Alberdi. Para consultas, correcciones o solicitudes relacionadas con privacidad puede escribir a: distribuidoraalberdi1988@gmail.com.

2. Datos que procesa la aplicación

Según las funciones utilizadas, la aplicación puede procesar:

  • Datos de acceso: correo electrónico y credenciales de autenticación gestionadas mediante Supabase Auth.
  • Datos de usuarios internos: nombre, apellido, rol, estado de la cuenta y vínculo con pedidos y clientes.
  • Datos de clientes comerciales: nombre del comercio, dirección, propietario o responsable, teléfono, localidad, zona y observaciones.
  • Ubicación precisa: latitud, longitud y fecha de actualización de ubicación de un cliente cuando el usuario solicita registrar o actualizar esa ubicación.
  • Datos de pedidos: cliente, preventista, tipo de precio, productos, cantidades, importes, fechas, estado, facturación, entrega, comisiones y observaciones del pedido.
  • Datos administrativos y comerciales: información necesaria para facturación, seguimiento de entregas, recaudación, saldos, costos y reportes internos.

3. Uso de la ubicación

La aplicación puede solicitar permiso para acceder a la ubicación precisa del dispositivo con el fin de registrar o actualizar la ubicación de un cliente. La ubicación se obtiene cuando el usuario utiliza expresamente esa función. La aplicación no utiliza la ubicación para seguimiento continuo en segundo plano.

4. Finalidades del tratamiento

La información se utiliza exclusivamente para funciones operativas y administrativas de Distribuidora Alberdi, entre ellas:

  • autenticar usuarios autorizados;
  • gestionar clientes y sus datos de contacto;
  • registrar y consultar ubicaciones de clientes;
  • crear, revisar, facturar y gestionar pedidos;
  • controlar entregas, pagos, saldos y recaudación;
  • calcular costos, comisiones y resúmenes comerciales;
  • generar, imprimir o compartir documentos cuando el usuario solicita esas acciones.

5. Almacenamiento y proveedores

La aplicación utiliza Supabase como infraestructura de autenticación y base de datos. La información necesaria para el funcionamiento del sistema puede almacenarse y procesarse mediante los servicios de Supabase, sujetos a sus propias medidas de seguridad y condiciones.

La aplicación también utiliza funciones del sistema operativo para compartir, abrir enlaces, imprimir o guardar documentos cuando el usuario inicia esas acciones. No utilizamos SDK de publicidad ni hemos incorporado servicios de analítica publicitaria en la aplicación.

6. Compartición de información

Distribuidora Alberdi no vende datos personales. La información se utiliza para la operación interna del sistema y puede ser procesada por proveedores técnicos necesarios para prestar el servicio, como Supabase. Cuando el usuario elige compartir o imprimir un documento, el contenido puede pasar a la aplicación o servicio seleccionado por el propio usuario en su dispositivo.

7. Seguridad

Se aplican controles de acceso mediante autenticación y permisos de base de datos para limitar el acceso a la información según el rol del usuario. Aun así, ningún sistema informático puede garantizar seguridad absoluta.

8. Conservación y eliminación

Los datos se conservan mientras sean necesarios para la operación del negocio, la administración de pedidos, facturación, entregas, cobranzas y demás obligaciones comerciales o legales aplicables. Las solicitudes de corrección o eliminación pueden enviarse al correo de contacto indicado en esta política.

9. Personas menores de edad

Esta aplicación está destinada al uso interno de Distribuidora Alberdi y sus usuarios autorizados. No está dirigida a niños ni diseñada para recopilar intencionalmente información de menores de edad.

10. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando cambien las funciones de la aplicación, los servicios utilizados o los requisitos legales y de Google Play. La versión vigente se publicará en esta misma página con su fecha de actualización.
